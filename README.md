# GitHub Visualization

An interactive GitHub repository analytics and visualization dashboard built using Django, Python and D3.js.

## Project Overview

GitHub repositories contain valuable development history such as commits, contributors, file changes, additions and deletions.

This project analyzes Git repository history and presents the information through interactive visualizations.
